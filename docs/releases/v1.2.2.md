Cut Browser 1.2.2 makes **About Cut Browser** in Settings show Cut Browser's own updates. It's built on Firefox <!-- firefox --> and Tor from Tor Browser <!-- tor -->.

## Which file do I need?

If you have Cut Browser 1.2.0 or 1.2.1 on Windows, you don't need a file: it installs this update by itself, within six hours, when you close it (or straight away with **Restart to update** in the menu).

| Your computer | Download |
| --- | --- |
| Windows 10 or 11 (64-bit) | `Cut-Browser-1.2.2-Setup-x64.exe` |
| Ubuntu, Debian, Linux Mint, Pop!_OS | the `amd64.deb`: `sudo apt install ./cut-browser_*.deb` |
| Any other Linux (64-bit) | the `.tar.xz`: unpack it and run `./install.sh` |

Installing over an earlier version keeps your bookmarks, history and settings. <!-- signing --> `SHA256SUMS.txt` lists the checksum of every file.

## What's fixed

- **Settings → About Cut Browser** said "Updates disabled by your organization" (that's Firefox's own updater, which Cut Browser turns off). It now shows Cut Browser's updates: whether it's up to date, **Check for updates**, the download's progress, and **Restart to update** when a new version is ready.
- **Release notes, in Settings.** The version line shows Cut Browser's version alongside Firefox's, with **What's new** for the version you have. While an update waits, **What's new in Cut Browser** opens that version's notes, in *About Cut Browser* and in *Settings → Cut Browser → Updates*; otherwise **Show update history** lists every release.
- **Get help** and **Share ideas and feedback** go to Cut Browser's GitHub, not Mozilla's.
