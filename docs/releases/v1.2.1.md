Cut Browser 1.2.1 brings back the **downloads panel**. It's built on Firefox <!-- firefox --> and Tor from Tor Browser <!-- tor -->.

## Which file do I need?

If you have Cut Browser 1.2.0 on Windows, you don't need a file: it installs this update by itself, within six hours, when you close it (or straight away with **Restart to update** in the menu).

| Your computer | Download |
| --- | --- |
| Windows 10 or 11 (64-bit) | `Cut-Browser-1.2.1-Setup-x64.exe` |
| Ubuntu, Debian, Linux Mint, Pop!_OS | the `amd64.deb`: `sudo apt install ./cut-browser_*.deb` |
| Any other Linux (64-bit) | the `.tar.xz`: unpack it and run `./install.sh` |

Installing over an earlier version keeps your bookmarks, history and settings. <!-- signing --> `SHA256SUMS.txt` lists the checksum of every file.

## What's fixed

- **Downloads show their panel again.** When a download starts, the Downloads button appears beside the address bar and its panel opens, as in Firefox: with the download's progress, and buttons to open the file or show it in its folder. Earlier versions left the button out (Firefox leaves it off its toolbar when tabs are in the sidebar), so downloads happened without it.
- **In compact mode**, a panel that opens by itself, like a new download's, brings the toolbar out with it, instead of opening off the top of the window.
