The first release of **Cut Browser**: a private web browser for Windows and Linux, built on Firefox <!-- firefox -->, with **Cut Search** built in.

## Which file do I need?

| Your computer | Download |
| --- | --- |
| Windows 10 or 11 (64-bit) | `Cut-Browser-1.0.0-Setup-x64.exe` |
| Ubuntu, Debian, Linux Mint, Pop!_OS | the `amd64.deb`: `sudo apt install ./cut-browser_*.deb` |
| Any other Linux (64-bit) | the `.tar.xz`: unpack it and run `./install.sh` |

<!-- signing --> `SHA256SUMS.txt` lists the checksum of every file.

## What's in 1.0

- **Zen-style layout**: tabs down the side, the page as a rounded card, pinned tabs as tiles, split view and tab groups
- **Compact mode** (<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd>): the sidebar and toolbar tuck away and slide back when you point at the window's edge
- **Floating address bar**: typing opens the address bar in the middle of the window, over the dimmed page
- **Cut Search built in**: a private metasearch engine that runs on your own computer. It asks several search engines for you, without cookies or anything that identifies your browser, and they never see what you click. It's the default search and supplies the address bar's suggestions
- **Private by default**: no telemetry, studies or crash reports; strict tracking protection, HTTPS-Only Mode and Global Privacy Control; no prefetching or background check-ins; AI features and sponsored content off; uBlock Origin installed on first run
- **Firefox's own settings**, all still there, plus a **Cut Browser** section for the layout and Cut Search

## Updates

Cut Browser doesn't update itself from Mozilla (that would turn it back into plain Firefox). New versions are published here when Firefox releases security fixes; install a new version over the old one and your bookmarks, history and settings stay.
