Cut Browser 1.2 **keeps itself up to date**. It's built on Firefox <!-- firefox --> and Tor from Tor Browser <!-- tor -->.

## Which file do I need?

| Your computer | Download |
| --- | --- |
| Windows 10 or 11 (64-bit) | `Cut-Browser-1.2.0-Setup-x64.exe` |
| Ubuntu, Debian, Linux Mint, Pop!_OS | the `amd64.deb`: `sudo apt install ./cut-browser_*.deb` |
| Any other Linux (64-bit) | the `.tar.xz`: unpack it and run `./install.sh` |

Installing over 1.0 or 1.1 keeps your bookmarks, history and settings. <!-- signing --> `SHA256SUMS.txt` lists the checksum of every file.

## What's new

- **Automatic updates on Windows.** Cut Browser asks GitHub for new versions every six hours. When there is one, it downloads it in the background, checks it against the release's checksums, and installs it when you close Cut Browser: your bookmarks, history, settings and extensions stay. If a Tor window is still open, the update waits until it's closed too.
- **Restart to update**: when an update is ready, the menu offers to install it straight away and reopen your tabs.
- **On Linux**, *Settings → Cut Browser* tells you when a new version is out.
- *Settings → Cut Browser → Updates* shows what's happening, checks on demand, and can turn automatic updates off. The version number of Cut Browser is in *Settings → Cut Browser → About*, too.

**This is the last update you install by hand.** Install 1.2 over 1.0 or 1.1 once, and from then on Cut Browser updates itself.

Update checks contact GitHub (its API and its download servers) and send no cookies.
